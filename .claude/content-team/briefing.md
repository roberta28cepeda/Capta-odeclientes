# Briefing de conteúdo
## Negócio
- Produto: Capta • ó de clientes — conjunto de automações de prospecção e vendas para freelancers/devs solo (achar leads sem site, lista de devedores PGFN, proposta/contrato em PDF, análise pós-call, inbox com sugestão de resposta, WhatsApp via Cloud API oficial).
- Oferta: sistema que substitui um vendedor/SDR para quem vende sites e sistemas sozinho — encontra o lead, gera a proposta, analisa a call e sugere a resposta certa, do primeiro contato ao fechamento.
- Público: freelancers e devs solo que vendem sites/sistemas para pequenas empresas locais e não têm tempo (nem time) para prospectar e vender.
- Posicionamento: alternativa de baixo custo e sem dependência de agência ou ferramentas fragmentadas — um fluxo só, do lead à venda fechada.
- Diferencial: automação ponta a ponta (prospecção → proposta → call → resposta) usando IA para gerar o conteúdo comercial, com fontes de lead que não dependem só de API paga (ex.: lista de devedores da PGFN).
